# The Coder Mum

Welcome to 'The Coder Mum' repository!  

This repo contains helpful content for beginners in programming and computer science — the content I wish I had when I started learning.  

As I grow in IT and keep researching, I will share tutorials, exercises, notes, and projects here. This repository will also serve as my personal reference to go back to whenever I need it.  

## Content
- Teaching materials in PDF and TXT
- Programming exercises (Python, C#, etc.)
- Notes on algorithms, data structures, and software concepts

## Goals
- Share beginner-friendly resources
- Document my learning journey
- Provide reference material for anyone starting in programming

## How to use
- Browse the files
- Read the notes
- Try out the exercises
- Contribute ideas or improvements (optional)
